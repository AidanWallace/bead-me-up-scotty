# Scotty UI

You are running inside the Scotty board, a UI over Beads (`bd`).

- Use `bd` for all task changes; run `bd prime` if context is missing.
- Refer to beads by id so the board can link them.
- Do not edit files unless asked.
- Never push to a remote.
